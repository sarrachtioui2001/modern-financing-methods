MODERN FINANCING METHODS
Interactive presentation · Sarra Chtioui · Finance for the Engineer
=====================================================================

OPEN IT
  Double-click index.html. It opens in Chrome or Edge.
  No internet needed: everything is in the lib and photos folders.
  Keep index.html, lib/ and photos/ together.

PRESENT IT
  Next / previous ..... Right / Left arrow, Space, a clicker, or a mouse click
  Full screen ......... F
  Overview of slides .. Esc
  Speaker view ........ S  (opens a window with notes, timer and next slide)
  Slide 11 ............ click a need: the matching methods light up

DESIGN
  Palette: university blue #1F4E9C (structure), purple #6D3FA8 (highlights),
  green #2E7D5B and red #B4432F (advantages and limits only),
  ink #1B2333 text on warm white #F7F6F2.
  Fonts: Fraunces (titles) and Inter (text).

BUILT WITH
  Reveal.js 5.1 (slides) · GSAP 3.12 (animations) · three.js r128 (3D wheel)
  HTML, CSS, JavaScript and SVG, in a single file: index.html
  3D models, all CC0 (free, no credit required):
    buildings, truck, trees: Kenney (kenney.nl)
    people: Quaternius (quaternius.com), via poly.pizza
  They are embedded in lib/models.js; the original .glb files are in models/.

BACKUP
  modern_financing.pdf, in the folder above, has the same content as
  classic Beamer slides.
